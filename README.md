# 个人记账本

一个面向日常个人收支管理的本地 Web 应用，通过浏览器记录收入与支出、查看明细并了解收支情况。

## 功能规划

- **记录收支**：填写日期、金额、类别和备注，区分收入与支出。
- **查看账目**：查看最近记录，分页浏览历史明细。
- **组合筛选**：按日期范围、收支类型、类别和金额范围查询。
- **收支统计**：展示总收入、总支出、结余和类别支出汇总。
- **本地保存**：使用 JSON 文件保存账目，重启后继续读取。

## 技术方案

前端采用 Vue 3 + Vite，后端采用 Python + Flask。金额以整数分保存和计算，界面以元展示。交付版计划由 Flask 同时提供页面和 API，浏览器访问本地服务即可使用。

应用定位为单机、单用户使用，首版不包含账户登录和云同步。

## 当前进度

当前已接入本地存储、收入与支出录入、记录查询、筛选分页、收支统计和前端页面。

## 运行方式

环境：Python（本轮使用 3.11.9 验证；1 号另有 3.13 环境验证记录）、Flask 3.1.2。开发构建需要兼容 Vite 的 Node.js 与 npm，依赖以锁文件为准。

1. 运行 `scripts\setup.bat` 创建虚拟环境并安装后端依赖；开发测试可使用 `scripts\setup.bat dev`。
2. 在根目录执行 `npm --prefix frontend ci` 和 `npm --prefix frontend run build`。
3. 使用 PowerShell 将构建产物复制到发布目录：`New-Item -ItemType Directory -Force web; Copy-Item frontend/dist/* web -Recurse -Force`。
4. 运行 `scripts\start.bat`，访问 `http://127.0.0.1:5000`。也可使用 `.\.venv\Scripts\python.exe backend/run.py` 仅启动 API。
5. 数据位于 `data/records.json`，首次运行自动初始化；请保留并备份此文件，演示样例不自动覆盖正式账本。

发布运行包已包含构建后的前端资源，无需安装 Node.js；首次安装后端依赖需要联网。

## 本地打包

运行 `scripts\package.bat v1.0.0`，生成 `release/v1.0.0.zip` 及 SHA256。脚本会重新构建前端，保留其他版本；同版本文件已存在时会报错，请先另存旧包或使用新版本号。

运行包无需 Node.js，安装与启动见 [运行包说明](docs/运行包说明.md)，模块介绍见 [代码要点](docs/代码要点.md)。
