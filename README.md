# 个人记账本

一个面向日常个人收支管理的本地 Web 应用，通过浏览器记录收入与支出、查看明细并了解收支情况。

## 功能规划

- **记录收支**：填写日期、金额、类别和备注，区分收入与支出。
- **查看账目**：查看最近记录，分页浏览历史明细。
- **组合筛选**：按日期范围、收支类型、类别和金额范围查询。
- **收支统计**：展示总收入、总支出、结余和类别支出汇总。
- **本地保存**：使用 JSON 文件保存账目，重启后继续读取。

## 技术方案

前端采用 Vue 3 + Vite，后端采用 Python + Flask。金额以整数分保存和计算，界面以元展示。交付版计划由 Flask 同时提供页面和 API，浏览器访问本地服务即可使用。

应用定位为单机、单用户使用，首版不包含账户登录和云同步。

## 当前进度

当前已同步主分支项目骨架及类别、录入/筛选/分页参数校验模块。本地 09 分支已实现记录表格、最近十笔记录、刷新与异常提示，并提供独立模块预览。完整记账流程及运行包仍在开发中，暂未提供完整应用的启动方式。

## 预览记录展示模块

需要兼容的 Node.js 24.12 或以上版本及 npm；首次安装依赖需要联网。在项目根目录执行：

```powershell
cd tests/frontend/records
npm ci
npm test
npm run preview
```

浏览器访问 http://127.0.0.1:5179，可切换正常记录、空账本、请求失败和新增后刷新。这里使用明确标记的内存样例，不读写真实账本，也不代表完整应用已经接通。

整合版仍采用 Flask 提供页面和 API 的方式，用户数据保存到 data/records.json。完整启动说明由框架负责人在整合验证后补充。
