# 个人记账本

一个面向日常个人收支管理的本地 Web 应用，通过浏览器记录收入与支出、查看明细并了解收支情况。

## 功能规划

- **记录收支**：填写日期、金额、类别和备注，区分收入与支出。
- **查看账目**：查看最近记录，分页浏览历史明细。
- **组合筛选**：按日期范围、收支类型、类别和金额范围查询。
- **收支统计**：展示总收入、总支出、结余和类别支出汇总。
- **本地保存**：使用 JSON 文件保存账目，重启后继续读取。

## 技术方案

前端采用 Vue 3 + Vite，后端采用 Python + Flask。金额以整数分保存和计算，界面以元展示。交付版计划由 Flask 同时提供页面和 API，浏览器访问本地服务即可使用。

应用定位为单机、单用户使用，首版不包含账户登录和云同步。

## 当前进度

当前已建立项目目录骨架，实现类别及参数校验；本分支补充记录表格、最近十条记录、刷新与异常提示，并提供独立组件测试和样例预览。完整记账流程及运行包仍在开发中，暂未提供完整应用的启动方式。
