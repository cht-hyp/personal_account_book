## 4. 浏览器交互观测（豆包内置浏览器，Chromium，视口 520×866）

保存前：

```text
最近记录
共 4 条
```

在页面外新增一条 30.00 元购物记录（Mock 返回 201，total=5）后，点击占位表单的保存按钮：

```text
最近记录
共 5 条
2026-11-07  支出  购物  -30.00  刷新验证
...
已保存：餐饮
```

同一时刻的网络记录出现新的请求（说明刷新由 `refreshKey` 触发，不是整页重载）：

```text
http://127.0.0.1:5055/api/records?limit=10
http://127.0.0.1:5055/api/records?limit=10
http://127.0.0.1:5055/api/records?limit=10
```

统计页读数（与 Mock 契约检查口径一致）：

```text
收入 1000.00   支出 75.50   结余 924.50   记录数 5
类别支出：餐饮 40.50 (54%)  购物 30.00 (40%)  交通 5.00 (7%)
```

类别故障注入后的页面文本：

```text
类别加载失败：Mock 故意注入的类别故障
错误码 INTERNAL_ERROR。录入表单在类别可用前不会提交。
[重试加载类别]
类别尚未可用，骨架按钮已禁用。
```

关闭注入并点击重试后，错误条消失、类别恢复为“收入 5 类、支出 8 类”。

停掉 Mock 后触发刷新：

```text
最近记录
无法连接本地服务，请确认后端已启动后重试
[重新加载]
```

页面没有把失败显示成“暂无数据”。

重新进入页面会重新请求（从统计页切回记一笔后，网络记录新增一次 `GET /api/records?limit=10`，页面显示“共 3 条”，与重启后的 Mock 初始数据一致）。
