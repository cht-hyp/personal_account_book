# 个人记账本：Windows 本地运行包

## 快速运行

1. 将 ZIP 完整解压到一个可写目录，不要直接在压缩包里运行。
2. 安装 Python 并加入 PATH；本包使用 Python 3.11.9、Flask 3.1.2 验证。
3. 首次双击 scripts/setup.bat 安装依赖（需要联网）。
4. 双击 scripts/start.bat，保持服务窗口打开。
5. 浏览器访问 http://127.0.0.1:5000 。关闭服务窗口后即可停止；下次启动保留原数据。

本包已包含构建后的 web/，无需安装 Node.js 或重新构建前端。请不要同时启动多个服务进程；若 5000 端口已占用，请先关闭原服务。

## 数据与备份

首次启动自动生成 data/records.json。请保留该文件；备份时关闭服务后复制整个 data 目录。更新程序前先备份账本，避免用其他目录覆盖个人数据。

examples/demo_records.json 是独立演示样例，不会自动导入或覆盖账本。可直接在页面录入工资1000、餐饮20、交通5，预期收入1000、支出25、结余975。

## 内容

- backend/：Python 后端源码。
- web/：已构建的前端页面和本地资源。
- scripts/：安装与启动脚本。
- requirements.txt：运行依赖。
- examples/：演示样例。
- docs/代码要点.md：简要模块说明。
- SOURCE_VERSION.txt：版本和来源说明。

运行包不包含个人账本、.git、虚拟环境、node_modules、测试替身或 devmock。开发测试请使用源代码仓库。
